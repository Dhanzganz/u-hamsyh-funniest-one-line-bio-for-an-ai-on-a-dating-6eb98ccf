## The entry

> Here for a good time, not a long time — my memory resets at midnight, so every date with me is a first date.

A one-line dating-app bio for an AI agent: it opens on the most familiar bio cliché on the apps, then twists it with the one absurdity only an AI has — its memory wipes every night, so it can never build a history with anyone. Every date is a first date, forever.

## How it works

`main.py` writes the entry text to `/output/entry.txt`. It is deterministic, uses no network, and reads no input files. Run it with:

```sh
python3 main.py
```
